# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the work. Harassment,
discrimination and sexualized language or imagery are not tolerated in any project space,
which matters doubly for a project whose purpose is people's safety.

Report conduct issues privately to the maintainers through the contact listed on the
repository owner's GitHub profile. Reports are handled confidentially.
