# Accessibility statement: [COMMUNITY]

> ⚖️ Draft for review by an accessibility consultant. Last updated [EFFECTIVE_DATE].

We want everyone to be able to use [COMMUNITY]. The service aims to meet **WCAG 2.1 level AA** and the
Israeli standard **IS 5568** (based on WCAG 2.0 AA) 📘.

## What we did

- Built for screen readers (VoiceOver, TalkBack) and for keyboard-only use on the web, with a visible
  focus.
- Text can be enlarged up to 200% without losing content.
- Full right-to-left support in Hebrew.
- Every swipe has a button; no action depends on gestures, colour or sound alone.
- Reduced motion is respected; no flashing content.
- Voice messages can be turned off by the receiver (they are not transcribed yet).
- Forms have labels and clear error messages; contrast is checked, including for the community's own
  brand colour.
- Every screen covered by the project's end-to-end tests is checked automatically (axe-core, WCAG 2.1
  A/AA) in English and Hebrew. Automated checks find only part of the problems: [describe your manual
  review with assistive technology].
