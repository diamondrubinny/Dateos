# Sponsoring Dateos

Dateos is free for everyone, forever: no premium tier, no paywalls, no ads, no selling data.
Sponsorships pay for the things a safe dating platform needs and code alone cannot provide.

## Where the money goes

| Priority | Item                                                              | Why it matters                                       |
| -------- | ----------------------------------------------------------------- | ---------------------------------------------------- |
| 1        | Independent security audit and penetration test                   | The app stores location, photos and private messages |
| 2        | Accessibility audit (WCAG 2.1 AA / IS 5568)                       | Dating should work for everyone                      |
| 3        | Legal review of privacy, terms and consent templates (Israel, EU) | So every operator starts from a reviewed baseline    |
| 4        | Public demo instance and CI infrastructure                        | Lets people try Dateos without installing anything   |
| 5        | Translations and moderation tooling                               | Safer, more communities                              |

We will publish a yearly transparency report of income and spending.

## Monthly tiers (GitHub Sponsors)

| 🌍 Founding Partner | **$1,500 / month** | Large logo at the top of the README and docs site; acknowledged in release notes               |

## One-time amounts

**$5**, **$25**, **$100**, **$500**, or a custom amount.

## What sponsorship does not buy

To protect users and the project's independence, sponsorship never buys:

- access to any user data, or influence over moderation decisions
- changes to the matching algorithm that favour anyone
- a support SLA or private features (all features stay open source and free)

## Maintainer setup checklist

GitHub Sponsors tiers are configured in the GitHub dashboard, not in this repository:

1. Join GitHub Sponsors at <https://github.com/sponsors> (payout and tax details are required) 📘.
2. Create the tiers above with the descriptions from this table.
3. In repository **Settings → General → Features**, enable **Sponsorships**.
4. Merge `.github/FUNDING.yml` to the default branch so the **Sponsor** button appears.
5. Optional: add Open Collective, Ko-fi or Liberapay to `FUNDING.yml` once the accounts exist.
